# WinFormsApp1

This project is a bilingual dictionary desktop application for translating between English and French.

## What it does

The app lets users:
- enter a word in English or French,
- translate it to the other language,
- view the word type and usage examples,
- manage dictionary entries in the database.

The interface is built as multiple Windows Forms screens, and the main startup is defined in `Program.cs`.

## Technology

- C#
- .NET 6 for Windows
- Windows Forms (WinForms)
- Microsoft SQL Server (`System.Data.SqlClient`)

This is a Windows desktop application designed to work as a simple dictionary and data management tool for bilingual translations.
